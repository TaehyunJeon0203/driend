1. 수집하는 개인정보

Driend는 아래의 사용자 데이터를 수집 및 처리합니다.

데이터 유형세부 항목사용 목적
위치 정보 정확한 위치(GPS 좌표), 백그라운드 위치 주행 경로 기록, 방문 도시 감지, 자동 주행 시작/종료
개인 정보 이메일, 닉네임, 프로필 사진 계정 식별, 친구 추가, 랭킹
사진/비디오 방문 지역 사진 사진 모드 지도 시각화
앱 활동 주행 거리/속도/시간, 제로백 측정값, 통계 주행 기록, 랭킹, 통계 제공
사용자 생성 콘텐츠 지역 사진, 차량 정보 앱 기능 제공
기기 식별자 Supabase 익명 세션 ID 게스트 로그인 세션 유지

2. 데이터 수집 방법

  • 사용자가 카카오 로그인, Apple로 로그인 또는 게스트 로그인을 선택할 때 계정 정보 수집
  • 주행 기록 중 백그라운드에서 GPS 위치 정보 수집
  • 사용자가 지역 사진 등록 시 사진 라이브러리 접근 (사용자 명시적 선택)
  • 제로백 측정 시 가속도계 및 GPS 데이터 수집

3. 데이터 사용 목적

  • 주행 경로 기록 및 통계 제공
  • 방문 도시 자동 감지 및 사진 모드 지도 표시
  • 친구 추가 및 카테고리별 랭킹 산출
  • 제로백(0→100km/h) 측정 기능
  • 서비스 운영 및 품질 개선

4. 데이터 보관 및 삭제

사용자 데이터는 계정이 유지되는 동안 보관되며, 계정 삭제 요청 시 즉시 영구 삭제됩니다. 별도의 보관 기간은 없습니다.

계정 삭제 방법은 계정 삭제 안내 페이지를 참고하세요.

5. 데이터 공유

Driend는 사용자 데이터를 제3자에게 판매하지 않습니다. 데이터는 아래 서비스 인프라에만 사용됩니다:

  • Supabase (데이터베이스, 스토리지, 인증)
  • 네이버 지도 API (지도 표시)
  • Mapbox Map Matching API (경로 스냅)
  • 카카오 로그인 SDK (인증)
  • Apple Sign In (iOS 인증)

6. 데이터 보안

모든 데이터 전송은 HTTPS/TLS 1.2+로 암호화됩니다. 비밀번호는 평문으로 저장되지 않으며, 인증은 OAuth 제공자(카카오, Apple)를 통해 처리됩니다.

7. 사용자 권리

사용자는 언제든지 다음을 할 수 있습니다:

  • 앱 내에서 개별 주행 기록 삭제
  • 앱 내에서 방문 도시 사진 삭제
  • 앱 내에서 프로필 사진 삭제
  • 회원 탈퇴를 통한 전체 데이터 영구 삭제
  • 이메일(jeontaehyun0203@gmail.com)을 통한 삭제 요청

8. 어린이 개인정보 보호

Driend는 13세 미만 어린이를 대상으로 하지 않으며, 어린이의 개인정보를 고의로 수집하지 않습니다.

9. 개인정보처리방침 변경

본 방침은 업데이트될 수 있으며, 변경 시 이 페이지에 게시됩니다. 중대한 변경이 있는 경우 앱 내 알림으로 안내합니다.
