계정 삭제 안내

계정 삭제 방법

방법 1 · 앱 내 회원 탈퇴
  1. Driend 앱을 실행합니다.
  2. 하단 탭에서 프로필을 선택합니다.
  3. 화면 하단의 회원 탈퇴 버튼을 탭합니다.
  4. 확인 대화상자에서 탈퇴를 선택합니다.

탈퇴 확인 즉시 모든 데이터가 서버에서 영구적으로 삭제됩니다.

방법 2 · 이메일 요청

아래 주소로 "계정 삭제" 제목의 이메일을 발송해 주세요. 가입 시 사용한 계정 정보(이메일 또는 닉네임)를 본문에 포함해 주시면 영업일 기준 2일 이내에 처리됩니다.

jeontaehyun0203@gmail.com

삭제되는 데이터

  • 계정 정보 (이메일, 닉네임, 가입일시)
  • 프로필 사진
  • 모든 주행 기록 (경로 좌표, 거리, 속도, 시간, 시작/도착지 주소)
  • 방문 도시 기록
  • 사용자가 등록한 지역 사진
  • 차량 정보 (제조사, 모델, 연식, 색상)
  • 친구 관계 (친구 요청 및 수락 내역)
  • 제로백(0→100) 측정 기록
  • 통계 집계 데이터 (월별 주행량 등)

데이터 보관 기간

계정 삭제 요청 즉시 모든 데이터가 영구적으로 삭제되며, 어떠한 데이터도 보관되지 않습니다. 삭제 후에는 복구가 불가능합니다.
